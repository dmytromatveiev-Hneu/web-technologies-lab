# Web Technologies Lab

Це навчальний репозиторій для виконання лабораторних робіт і завантаження наступних робіт.

## Лабораторна робота №1

Тема: Основи роботи з GitHub.

## Автор

GitHub: dmytromatveiev-Hneu

## Структура

- `index.html` — навчальна вебсторінка.
- `style.css` — стилі вебсторінки.
- `images/` — зображення навчального проєкту.

Наступні лабораторні роботи можна додавати в окремі папки `lab-02`, `lab-03` тощо.

## Індивідуальне завдання: варіант №3

Створити репозиторій для JavaScript-проєкту.

Реалізовано калькулятор вартості покупки: `script.js` обробляє форму, перевіряє кількість і ціну та показує суму в гривнях.

### Запуск

Завантажте репозиторій через **Code → Download ZIP**, розпакуйте архів і відкрийте `index.html` у браузері. Встановлювати бібліотеки не потрібно.

Приклад: кількість **2**, ціна **150** → **300,00 грн**.
